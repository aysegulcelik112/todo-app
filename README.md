# 📝 Kodlama Ajandam

Öncelik, kategori, tekrarlayan görev, XP/seviye ve streak (gün serisi) sistemine sahip; tamamen vanilla **HTML, CSS ve JavaScript** ile geliştirilmiş bir yapılacaklar listesi (to-do list) uygulaması.

## ✨ Özellikler

- ✅ Görev ekleme, düzenleme, silme, tamamlama
- 🟢🟡🔴 Öncelik seviyeleri (düşük / orta / yüksek)
- 🏷️ Kategoriler: İş, Kişisel, Alışveriş, Sağlık, Öğrenme, Diğer
- 📅 Son tarih (deadline) belirleme ve gecikme uyarısı
- 🔁 Günlük / haftalık / aylık tekrarlayan görevler
- ⭐ Görevleri favorilere ekleme
- 📝 Görevlere not ekleme
- 🔍 Arama ve filtreleme (aktif, tamamlanan, favori, bugün, bu hafta)
- 🎮 **Oyunlaştırma:** XP kazanma, seviye atlama, günlük seri (streak) ve başarımlar
- 🎨 4 farklı tema (Retro, Dark, Minimal, Neon)
- 📊 İstatistikler: verimlilik skoru, kategori dağılımı, başarımlar
- 📤📥 JSON/CSV olarak dışa aktarma, JSON içe aktarma, yazdırma
- ⌨️ Klavye kısayolları (`Enter`, `Ctrl+Enter`, `Ctrl+/`, `Esc`)
- 💾 Verileriniz tarayıcının `localStorage`'ında saklanır — sunucu gerekmez

## 🚀 Kullanım

Projeyi klonladıktan sonra `index.html` dosyasını tarayıcınızda açmanız yeterlidir:

```bash
git clone https://github.com/KULLANICI_ADIN/kodlama-ajandam.git
cd kodlama-ajandam
```

Ardından `index.html` dosyasına çift tıklayın veya bir canlı sunucu (ör. VS Code "Live Server" eklentisi) ile açın.

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript (framework/kütüphane yok)
- Tarayıcı `localStorage` API'si
